Python Basics Practice Project

This repository contains beginner-level Python programs created for practicing basic concepts such as input/output, conditionals, file handling, and working with Excel files.

Project Structure
.
├── atm.py            # Simple ATM simulation (PIN, withdraw, enquiry)
├── filehandle.py     # Basic file handling operations
├── filehandle2.py    # Advanced file handling example
├── helloname.py      # Prints greeting with user name
├── printstat.py      # Simple print statement practice
├── salary15.py       # Checks salary condition (greater than 15000)
├── sheet1.xlsx       # Sample Excel file used in programs
└── README.md

Requirements

Python 3.x

(Optional) Excel-related libraries if used (like openpyxl or pandas)

Check Python version:

python --version

How to Run the Programs

Clone the repository:

git clone <repository-url>


Navigate to the project folder:

cd python-basics-practice


Run any Python file:

python atm.py


Example:

python salary15.py

Program Descriptions

atm.py – Simulates basic ATM operations using PIN verification

salary15.py – Checks whether employee salary is greater than 15000 (True/False)

filehandle.py / filehandle2.py – Demonstrates file read/write operations

helloname.py – Takes user input and prints a greeting

printstat.py – Basic printing and formatting practice
